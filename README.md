# ECG Signal Denoising

ELEC5305 Project

This project investigates ECG signal denoising using digital filtering
and wavelet-based methods.

The project will compare different denoising techniques using performance
metrics such as SNR, MSE and RMSE.

## Tools
- Python
- NumPy
- SciPy
- PyWavelets
- WFDB

## Dataset
MIT-BIH Arrhythmia Database
